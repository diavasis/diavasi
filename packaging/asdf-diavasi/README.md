# asdf-diavasi

asdf plugin that installs `diavasi` from [GitHub Releases](https://github.com/diavasis/diavasi/releases).

```bash
asdf plugin add diavasi https://github.com/diavasis/asdf-diavasi.git
asdf install diavasi 0.12.0
asdf global diavasi 0.12.0
diavasi --version
```

Publish this directory to `diavasis/asdf-diavasi` (or keep developing from the monorepo path).
